Standard Denial Handling Procedures
Eligibility · Pre-Authorization · Medical Necessity
A
CARC 27 (Coverage Terminated): Verify active coverage on DOS via 270/271 real-time eligibility. If active, submit eligibility screenshot with corrected claim. If truly terminated, transition to secondary or self-pay.
B
CARC 197 / 15 (Prior Auth Absent): Contact payer authorization unit for retrospective review within timely window (24–72 hours for emergencies). Add valid PA# in Box 23 and resubmit.
C
CARC 50 (Medical Necessity): Pull local MAC LCD/NCD. Verify if clinical records document conservative therapy (e.g., 6 weeks PT/medication trial for lumbar spine MRI). Request peer-to-peer if over $300.
