Denial Work Queue
Full CARC/RARC action matrix — all 9 denial categories
3.1 Eligibility — CARC 26, 27, 31, 200, 204
CARCRARCDescriptionAction Steps
27N30Coverage terminatedVerify in MedQ. If active on DOS: get eligibility screenshot, resubmit. If truly ineligible → Bill to Patient (§10).
26N30Prior to coverageConfirm effective date vs DOS in MedQ. If retroactively backdated: get payer confirmation, resubmit. If genuinely prior → Bill to Patient.
31MA61Patient not identifiedVerify name, DOB, Member ID in MedQ + Veradigm. Correct discrepancy, resubmit. If still unresolved: call payer, get rep name and reference #.
200N30Lapse in coverageVerify lapse dates in MedQ. If retroactive reinstatement: get letter, resubmit. If confirmed lapse → Bill to Patient.
204N115Not covered under planReview plan in MedQ. Route to Coding Review for ICD-10 maximization. If excluded: adjust per contract or bill patient if ABN signed.
3.2 Authorization — CARC 15, 197, 96
CARCRARCDescriptionAction Steps
15N4Auth missing/invalidCheck MedQ Authorizations. If auth exists: add to claim, resubmit. If not obtained: check retro-auth with payer, document rep + ref #.
197N4No precertificationGet auth from MedQ or call payer. If retro-auth allowed: resubmit with auth #. If not: initiate appeal via Medical Records (§6) with LMN.
96N181No auth for procedureConfirm auth requirement per payer policy. If appeal pathway: route to Medical Records (§6). If no pathway: escalate to supervisor.
3.3 Medical Necessity — CARC 50, 56, 167, 49
CARCRARCDescriptionAction Steps
50N115Not medically necessaryRoute to Coding Review + Medical Records simultaneously. Coder verifies ICD-10 specificity. Submit appeal with LMN, clinical documentation, and LCD/NCD reference.
56N115Experimental/InvestigationalPull payer LCD/NCD. Submit appeal with FDA documentation, published clinical evidence, and physician justification letter.
167N115Diagnosis not coveredRoute to Coding Review — verify ICD-10 accuracy and CPT-to-DX linkage. If incorrect: correct + resubmit. If correct: appeal with clinical docs.
49N30Routine/screening deniedRoute to Coding Review. Verify diagnostic vs screening ICD-10. Correct to specific condition code and resubmit after coder approval.
3.4 Duplicates — CARC 18, 97  |  3.5 Billing Errors — CARC 16, 4, 5, 55, 181, 182
CARCRARCDescriptionAction Steps
18N20Exact duplicateCheck claim history. If original paid: close + document. If original denied: void duplicate, work original. Never resubmit a duplicate without voiding prior.
97N20Bundled (CCI)Route to Coding Review. Coder checks CCI edits. If modifier -59/-XS/-XE applies clinically: resubmit after coder approval. See §5 for bundling rules.
16MA130/N290Billing error/missing infoCheck RARC for specific field error (NPI, taxonomy, dates). Correct in Veradigm PM. Resubmit as corrected claim. Confirm clearinghouse acceptance.
4/5N19Modifier/POS inconsistentRoute to Coding Review. Coder reviews CPT/POS/modifier. Resubmit only after sign-off. Document coder name and date in Claim Notes.
181/182N19Wrong CPT/modifierRoute to Coding Review immediately. Do NOT change codes without coder authorization.
29N781TFL expiredSearch clearinghouse logs for proof of original submission. If proof found: submit TFL appeal. If no proof: Adjustment Review (§8.2) after supervisor approval.
119N362Benefit maximum reachedVerify accumulation in MedQ. Check for secondary → COB (§9). If no secondary: Adjustment Review (§8.1). If ABN signed: Bill to Patient (§10).
151N362Exceeds frequency/unitsRoute to Coding Review — verify units per clinical documentation. Cross-reference CPT frequency tables in §5. If within policy: appeal. If exceeded: Adjustment Review.

🚫
Critical RuleAR staff must NEVER alter CPT codes, ICD-10, or modifiers independently. All changes require certified coder approval before any resubmission.
5.1 Global vs TC / Professional Component (CARC 97)
ScenarioWho BillsModifierRule
GlobalSame provider owns equipment AND interpretsNo modifierNo -TC or -26 present. If added incorrectly → remove and resubmit.
Technical (-TC)Facility owns equipment; radiologist reads separately-TC on facility claimVerify -26 on radiologist professional claim separately.
Professional (-26)Radiologist interprets only — no equipment-26If global billed: unbundle to -26 with coder approval.

Medical Records & Appeals
Documentation requests · appeal package assembly · deadlines
⏰
Appeal Deadline AlertIf deadline is within 10 business days, escalate to supervisor immediately. Late appeals cannot be recovered.
6.1 Appeal Package Components
1
Appeal Cover Letter — patient name/DOB/member ID, DOS, claim #, CPT/ICD-10, denial CARC/date, specific request to overturn.
2
Original/Corrected Claim Copy — CMS-1500 or UB-04 with all fields legible.
3
Primary Denial Explanation — copy of EOB/ERA with denial reason highlighted.
4
Supporting Medical Records — physician orders, SOAP notes, imaging reports, lab results, procedure notes.
5
Physician Medical Necessity Letter — signed, patient-specific, directly addresses why service was medically necessary.
6
Clinical Guidelines / LCD/NCD — Medicare LCD, peer-reviewed literature, or clinical society guidelines supporting the service.

9
Coordination of Benefits (COB)
Dual coverage workflow and client escalation protocol
1
Verify all active insurances in MedQ for the DOS. Confirm COB order (birthday rule for dependents).
2
Submit to primary payer electronically via Veradigm PM.
3
Apply primary payment and contractual adjustment upon receipt of primary EOB/ERA.
4
If balance remains: submit crossover/secondary claim with primary EOB attached. Include primary ICN.
5
Apply secondary payment. Remaining balance → tertiary or Bill to Patient per contract.
📤
Escalate to Synergy HP ClientBoth primary + secondary deny each other as primary · Medicare as Secondary Payer (MSP) · Workers Comp/Auto lien disputes · Medicaid payer of last resort unresolved after 60 days · Patient disputes COB order · Any COB outstanding >60 days.
